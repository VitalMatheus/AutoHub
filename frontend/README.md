# AutoHub Frontend

Frontend React independente do backend NestJS.

```bash
npm install
npm run dev
```

O desenvolvimento usa `/api/v1` e faz proxy para `http://localhost:3000`. Para apontar diretamente para outra API, defina `VITE_API_URL` no ambiente. Os demais comandos são `npm run test`, `npm run typecheck` e `npm run build`.
